# What the api container installs.
#
# Separate from the repository's `requirements.txt` for two reasons, and the
# second is the one that bit:
#
#   * A server image has no business carrying pytest.
#   * `requirements.txt` documents the *development machine* -- versions
#     "verified working on Python 3.12.10 on Windows". Several of those pins
#     are Windows wheel versions with no Linux counterpart at the same number,
#     so installing that file verbatim inside a Linux container asks pip to
#     resolve a set that was never meant to co-exist there.
#
# Pinned to majors, not to the development machine's patch versions. The
# pipeline's numerics do not turn on a scipy patch release, and a container
# that cannot be rebuilt six months from now is worse than one that drifts.

# --- pipeline ---------------------------------------------------------------
numpy>=1.26,<2.0
scipy>=1.13,<2.0
pandas>=2.2,<3.0
scikit-learn>=1.5,<2.0
matplotlib>=3.8,<4.0
pyarrow>=16.0
tqdm>=4.66

# Headless: the api never opens a window, and opencv-python drags in GUI
# shared libraries that then have to be installed with apt. The -headless
# build is the same cv2 without them.
opencv-python-headless>=4.10,<5.0

# chirpsounder2 `lfm_ionogram-*.h5` products. Core, exactly as in
# pyproject.toml -- dual-format input is a permanent requirement, not a
# migration step (docs/architecture.md sec. 3). Omitting it here did not fail
# the build or the health check: `muf.io_chirp` imports it lazily, so the api
# came up green and then skipped every .h5 sounding at ingest as unreadable.
# An archive that loads 514 soundings on the host loaded 133 in the container.
h5py>=3.11,<4.0

# --- reference model --------------------------------------------------------
# IRI, for the `<Modeled>` values beside every measured one on the sounding
# page. Optional in the code -- `muf.reference.iri.available()` is checked and
# the panel says "not installed" rather than showing a blank -- but a
# comparison the operator cannot see is not a comparison, so the image carries
# it.
#
# Not a light dependency, whatever it looks like: it pulls netCDF4, cftime,
# fortranformat and opt_einsum, about 30 MB into the image. Verified to
# resolve on linux/py3.12 alongside the numpy<2 pin above (numpy 1.26.4,
# scipy 1.17.1, netCDF4 1.7.4) before it was added.
#
# It also needs a solar driver, which is a network fetch on a cold cache --
# see `MUF_INDEX_CACHE` in deploy/README.md, and the upstream panel on /ui for
# whether this host can still reach the servers that provide it.
PyIRI>=0.1.7

# --- service ----------------------------------------------------------------
# fastapi and starlette are version-coupled and break loudly when mismatched:
# fastapi 0.111.0 against starlette 1.0.0 makes a bare `FastAPI()` raise
# TypeError. Let pip pick the pair rather than pinning one of them.
fastapi>=0.115
uvicorn[standard]>=0.30
jinja2>=3.1
