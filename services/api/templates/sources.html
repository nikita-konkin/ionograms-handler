sounding mode

search records whatever sweeps past and infers the schedule. scheduled downconverts a fixed list at times it is told — named products, an absolute range zero, and no dependence on the detector. Leaving search mode requires a schedule in the same command: a scheduled station with an empty one records nothing while every process reports healthy.
