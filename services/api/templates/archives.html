Folders under {{ archive_root }} that this server keeps indexed. A scan runs the pipeline over whatever is new, so every sounding it loads arrives with its characteristics already derived — MUF, LOF, group range and SNR in the database, and the full scaling behind each sounding's page and its sao.xml. There is no separate step to compute them.
